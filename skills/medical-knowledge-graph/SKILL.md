# 医疗知识图谱备查手册（OpenCMKG）

图谱为全中文数据，**直接用中文名词检索，不要翻译**。常规调用顺序、关系类型词表、
效率规则均已写在工具说明中，本手册只保留备查细节。

## 一、实体类型（7 类）

| entity_type | 含义 |
| --- | --- |
| disease | 疾病 |
| symptom | 症状 |
| drug | 药物 |
| food | 食物 |
| department | 科室 |
| producer | 药企/生产商 |
| treatment | 检查与治疗手段 |

实体键格式：`CMKG:<类型>:<中文名>`，如 `CMKG:disease:高血压`、`CMKG:drug:阿司匹林`。

## 二、数据约束（必须遵守）

**1. 方向无语义。**
每条关系在正反两个方向各存一行，`src` / `dst` 不表示主体与客体。不要依据方向推断谁是原因、谁是结果。

**2. 推荐记录 ≠ 临床处方。**
`disease_recommand_drug` / `disease_common_drug` / `disease_need_treatment` 等关系只是图谱中记录的用药与治疗信息，**不等于个体化的临床处方**。表述时用"图谱记录……可用于……"，并提示具体用药需遵医嘱，不要直接给用户开药。

**3. 有记录不等于有因果。**
任何关系记录的存在都不等于已证明因果或疗效。多跳路径只表示"可达"，不等于因果链。饮食类关系（eat/recommand/noteat_food）是参考性建议，个体情况需遵营养师或医嘱。

**4. 图谱覆盖范围有限。**
本图谱没有副作用、禁忌、靶点、相互作用这类关系，不要声称"未检索到"它们，直接说明图谱不含该类数据即可。

## 三、图谱查不到时

一句话说明"图谱中没有该记录"，然后可结合你自己的医学知识给出方向性说明（并讲清哪些是图谱证据、哪些是你的知识），**不要用推测冒充图谱证据**。
