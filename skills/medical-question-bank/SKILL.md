# 医学题库备查手册

题库用于**检索真题**和**向用户出题互动**。何时检索、一次一题、不公布答案、
作答后判题讲解等纪律均已写在 `search_questions` / `present_quiz` 的工具说明中，
本手册只保留检索技巧备查。

## 检索技巧

- 查询词用**中文医学名词或知识点描述**（如"高血压 用药""糖尿病 并发症 诊断"），语义检索会按相关度返回。
- 检索结果按 score 降序，优先选用相关度最高且适合用户当前水平的题目。
- 用户指定学科（如"来道药理学的题"）时，`search_questions` 传入 `subject` 参数。
- 同一知识点反复出题时，避开已经出过的题目（可看本会话历史中已出过的题干）。
- 题库确实没有合适题目时，可按知识点自拟，并在讲解时说明该题为自拟。
